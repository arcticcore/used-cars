# Uppförandekod

Välkomna bidragsgivare oavsett erfarenhet eller bakgrund. Diskutera källor och sakuppgifter respektfullt. Kritik ska gälla innehållet, inte personen. Trakasserier, diskriminering, hot och publicering av andras privata uppgifter accepteras inte.

Underhållaren @arcticcore ansvarar för moderering och kan be om ändrat beteende, ta bort olämpligt innehåll eller begränsa deltagande. Rapportera olämpligt GitHub-innehåll via GitHubs rapporteringsfunktion; ta inte med privata uppgifter i ett offentligt issue. Sakliga överklaganden av innehållsbeslut kan göras i den berörda PR-diskussionen.
